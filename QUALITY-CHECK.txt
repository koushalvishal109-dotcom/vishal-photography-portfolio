CHOTU FRAME JOURNAL
===================

Asset and content checks
------------------------
- 30 WebP photographs are stored beside index.html.
- Original pixel dimensions are recorded in photos.js for every photograph.
- The browser reserves each image's aspect ratio before lazy loading begins.
- All 30 photo filenames and six collection covers resolve to repository assets.
- Public contact details use chotu.framejournal@gmail.com and
  @chotu.framejournal.
- The portfolio identity is Chotu Frame Journal, with Vishal credited
  personally as the photographer behind the journal.
- No em dash characters are used in the website copy.

Code and layout checks
----------------------
- The archive uses CSS Grid with row spans calculated before image loading.
- Image sizing is based on the recorded width and height attributes, not
  image load events or per-image ResizeObserver callbacks.
- Gallery positions remain reserved while lazy-loaded images arrive.
- Gallery sizing runs again only when the viewport is resized or a filter
  is changed.
- Responsive breakpoints are defined for desktop, tablet and mobile.
- A mobile navigation toggle, collection filters and keyboard-accessible
  photograph viewer are included.
- The website uses plain HTML, CSS and JavaScript with no build step,
  third-party JavaScript, remote font or required paid service.

Final visual check
------------------
- Preview the page on desktop and mobile before public launch.
- Scroll the full archive while images lazy-load to confirm cards stay fixed.
- Check gallery spacing and contact links in the browser.
