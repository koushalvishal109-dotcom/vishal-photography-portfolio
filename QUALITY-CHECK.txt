CHOTU FRAME JOURNAL
===================

Asset and content checks
------------------------
- 30 WebP photographs are stored beside index.html.
- Photo data and hero image references use the repository-root filenames.
- Six collections are defined; their displayed frame counts total 30.
- Collection labels use Agra, Shimla, Qutub Minar, Delhi Streets,
  Kathmandu, and Nepal: Hills and Fields.
- Public contact details use chotu.framejournal@gmail.com and
  @chotu.framejournal.
- The portfolio identity is Chotu Frame Journal, with Vishal credited
  personally as the photographer behind the journal.
- No em dash characters are used in the website copy.

Code and layout checks
----------------------
- The archive uses CSS Grid with explicit row spans calculated from
  each loaded photograph's rendered height and caption height.
- Grid auto-flow preserves the source order of photographs. Unlike CSS
  multi-column flow, the layout does not fill columns by vertical order.
- Image proportions remain natural. The grid is recalculated when image
  dimensions or layout widths change.
- Responsive breakpoints are defined for desktop, tablet and mobile.
- A mobile navigation toggle, collection filters and keyboard-accessible
  photograph viewer are included.
- The website uses plain HTML, CSS and JavaScript with no build step,
  third-party JavaScript, remote font or required paid service.
