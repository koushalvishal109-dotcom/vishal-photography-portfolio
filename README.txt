VISHAL — PERSONAL PHOTOGRAPHY PORTFOLIO
=======================================

This is a standalone, static website built around the supplied 30-photo set.
It has no website-builder dependency, no paid library, no external fonts and no
third-party scripts. The images and code are included in this folder.

PREVIEW
-------
Open index.html in a modern browser. The gallery, filters and image viewer
work locally without an internet connection.

PUBLISHING
----------
Upload the contents of this folder to any static website host that accepts
HTML, CSS, JavaScript and image files. Keep the images folder beside index.html.
No build step is required.

BEFORE PUBLIC LAUNCH
--------------------
1. Add the email address and social links you want to publish. The contact
   section intentionally does not invent any contact information.
2. Review all photo titles, captions and collection groupings.
3. Replace or refine the About text so it sounds exactly like you.
4. Add a custom domain and hosting only when you're ready.

EDITING
-------
- Photo titles, captions and collection labels: photos.js
- Page content: index.html
- Visual design and responsive layout: styles.css
- Interaction (filters, mobile menu, image viewer): main.js

All images are provided in the images folder as WebP files. Keep their names
unchanged unless you also update their paths in photos.js and index.html.
