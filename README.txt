CHOTU FRAME JOURNAL
===================

A personal photography journal by Vishal, also known as Chotu.

This is a standalone static website built around the supplied 30-photo set.
It has no website-builder dependency, no paid library, no external fonts and no
third-party scripts. The photographs and code are included in this repository.

PREVIEW
-------
Open index.html in a modern browser. The gallery, filters and image viewer
work locally without an internet connection.

PUBLISHING
----------
Upload the contents of this repository to a static website host that accepts
HTML, CSS, JavaScript and image files. Keep all WebP photographs beside
index.html. No build step is required.

EDITING
-------
- Photo titles, captions and collection labels: photos.js
- Page content, contact details and metadata: index.html
- Visual design and responsive layout: styles.css
- Gallery, filters, mobile menu and image viewer: main.js
- Browser tab icon: favicon.svg

The photo filenames are referenced directly from the repository root.
Keep the filenames unchanged unless you also update photos.js and index.html.
